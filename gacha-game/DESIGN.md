# 千霊（せんれい）ゲームデザイン v0.1

> タイトルは仮。絵はまだ無い前提で、仕組みと数値を固めるための設計書です。
> 数値はすべて [`sim/balance.py`](sim/balance.py) で検証しています（`python3 gacha-game/sim/balance.py`）。
> カードの数値は [`data/cards_season1.csv`](data/cards_season1.csv) にあります。

---

## 0. ひとことで

**大量に引いて、かぶったカードを千枚単位で合成し、育てた精霊を属性の読み合いで戦わせるゲーム。**

- くじは1回1円相当と非常に軽く、1日に数千回引ける。
- 図鑑は数日で埋まる。**遊びの中心は「同じカードを1000枚分集めてランクを上げる」合成**にある。
- 戦闘は精霊3体の三番勝負だけ。操作は並び順を決めることだけで、**相手の並びを読んで属性の有利を当てる**。

### コアループ

```
 くじを引く（10 / 100 / 1000連）
      │  かぶりは自動で合成
      ▼
 ランクが上がる ──▶ プロフィールに飾る（最大5枚）
      │
      ▼
 精霊に霊獣・霊具を付けて編成 ──▶ PvP（三番勝負）
      │                                │
      │                                ▼
      └────────── ガチャ券・名誉 ◀── ランキング報酬
```

## 2. くじ

### 2.1 排出率（1回あたり）

| レアリティ | 名前 | 排出率 | 第1期の種類数 | 1種あたり |
|---|---|---|---|---|
| ★5 | 神 | 0.07% | 2 | 0.035% |
| ★4 | 極 | 1.00% | 6 | 0.167% |
| ★3 | 稀 | 5.00% | 10 | 0.50% |
| ★2 | 珍 | 24.00% | 14 | 1.71% |
| ★1 | 常 | 69.93% | 20 | 3.50% |

- ★5が1枚出るまでの平均は **約1,429回**（無料枠で約7時間分）。
- **天井**: ★5が出ないまま3000回引いたら、次の1回は★5確定。天井まで行く人は約12%。

### 2.2 10連 / 100連 / 1000連の確率（変更提案）

ご要望の「10回1% / 100回8% / 1000回50%」を連ごとの確率として固定すると、1回あたりの確率は **10連が一番高く（0.100%）、1000連が一番低い（0.069%）** ことになります。
同じ1000回を引くなら、

| 引き方 | ★5が1枚以上出る確率 |
|---|---|
| 10連 × 100回 | **63.4%** |
| 100連 × 10回 | 56.6% |
| 1000連 × 1回 | 50.0% |

となり、「1000連は損」「10連を連打するのが正解」になってしまいます。

**提案: 1回あたりの確率を0.07%に統一する。** どの単位で引いても損得がなくなり、表示は次のようになります。

| 単位 | ★5が1枚以上出る確率 |
|---|---|
| 10連 | 0.70% |
| 100連 | 6.76% |
| 1000連 | **50.35%** |

1000連の「半分の確率で神が来る」という見せ場はそのまま残ります。単位ごとの違いは確率ではなく、**演出と手間**で付けます（1000連だけの専用演出「千引き」など、§9）。

### 2.3 くじ画面の作り

- 10連・100連・1000連の3ボタン。くじ枠が足りないボタンは押せない。
- 結果画面は個別のカードを並べるのではなく、**まとめ表示**にする。
  - 「新しく手に入れた」「ランクアップした」「★4以上」の3段だけ大きく見せ、残りは「★1 ×698」のように枚数で出す。
  - 合成値のゲージがまとめて伸びる演出を最後に入れる。

## 3. くじ枠（何回引けるか）

### 3.1 無料枠: 200回/時

- 18秒に1回分ずつ回復する（1時間で200回）。毎時0分にまとめて回復させると、その時刻にアクセスが集中するため。
- **1000回（5時間分）まで貯められる。**
  - 貯められないと、取り逃さないために毎時ログインが必要になり、社会人や学生が続けられない。
  - 1000回貯まると無料でも1000連が引ける。1000連は貯めて引くお楽しみになる。

### 3.2 上限突破（課金・1時間ごと）

その1時間に引ける回数を100円ごとに増やす。1回目の購入から60分間有効で、使い残しは消える。

| 購入 | その1時間の追加 | 合計（無料200回込み） | 1回あたり |
|---|---|---|---|
| 1回目 100円 | +400 | 600回 | 0.25円 |
| 2回目 100円 | +300 | 900回 | 0.33円 |
| 3回目 100円 | +200 | 1,100回 | 0.50円 |
| 4回目 100円 | +100 | **1,200回（上限）** | 1.00円 |

- 1時間に払えるのは最大400円。4回目の単価は千引き札と同じ1円/回になる。
- 「最大1000回」を「1時間に引ける回数の上限が1000回」と読む場合は、3回目を+100にして合計300円で打ち止めにする（§14）。

### 3.3 サブスク「月契（げっけい）」

- 毎日 **4000回分のサブスク枠**（朝5時に4000に戻る。繰り越しなし）。
- 価格は月額980〜1,480円あたりで検証する。ふだん2時間おきに遊ぶ人なら1日の回数がほぼ倍になるため、**課金の中心はサブスクになる見込み**。

### 3.4 千引き札（課金・1000円）

- 1000円で1000回。くじ枠と関係なく、いつでも引ける。
- 提案: **買ったらその場で1000連を引く「即時消費型」にする。** 有償通貨の残高を持たないので管理が軽くなる（§11）。
- 注意: 無料枠が1日数千回あるので、1000円で1000回は「割安感」が出にくい。「今すぐ1000連したい」ための商品と割り切るか、千引き札だけの演出やおまけを付ける。

### 3.5 1日に引ける回数の目安

| プレイヤー | 遊び方 | 回数/日 |
|---|---|---|
| ライト | 1日3回（7時・12時・21時） | 3,000 |
| ミドル | 起きている間2時間おき | 4,200 |
| サブスク | ミドル＋サブスク枠 | 8,200 |
| 重課金 | サブスク＋上限突破を1日4時間（1,600円/日） | 12,200 |

## 4. 合成とランク

### 4.1 自動合成

- 1枚目でカードを入手（ランク1）。
- 2枚目以降は自動で**合成値**になり、**合成値1000ごとにランク+1**。
- 合成値は余りを持ち越す（ランクアップ時に1000を引くだけ）。

### 4.2 合成値（変更提案）

「全カード一律1000枚」にすると、★5のランクアップが現実的ではありません（ライトで約950日、重課金でも約230日）。
そこで、**レアリティの高いカードほど1枚の合成値を大きくします。**

| | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---|---|---|---|---|
| 1枚の合成値 | 1 | 2 | 5 | 10 | 20 |
| ランク+1に必要な枚数 | 1000枚 | 500枚 | 200枚 | 100枚 | 50枚 |

特定の1枚をランク+1するまでの日数:

| | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---|---|---|---|---|
| 一律1000枚（ご要望どおり）・ライト | 9.5日 | 19日 | 67日 | 200日 | 952日 |
| **合成値（提案）・ライト** | 9.5日 | 9.7日 | 13日 | 20日 | 48日 |
| 合成値・ミドル | 6.8日 | 6.9日 | 9.5日 | 14日 | 34日 |
| 合成値・サブスク | 3.5日 | 3.6日 | 4.9日 | 7.3日 | 17日 |
| 合成値・重課金 | 2.3日 | 2.4日 | 3.3日 | 4.9日 | 12日 |

★1は「1000枚集まるとランクアップ」のまま。高レアほど少し時間がかかり、★5は育てる価値のある大物になります。

### 4.3 ランクの効果

- **ランク10までは能力が上がる**: 体・攻が1ランクごとに+3%（ランク10で×1.27）。
- **ランク11以降は見た目と名誉だけ**: 枠の色と飾ったときの演出が変わる。重課金でもPvPの強さに上限があり、それでも千枚単位で集め続ける理由を残す。

| ランク | 枠 | 意味 |
|---|---|---|
| 1〜4 | 素 | |
| 5〜9 | 銅 | |
| 10〜19 | 銀 | 能力の上限に到達 |
| 20〜49 | 金 | |
| 50〜99 | 虹 | |
| 100〜 | 神 | 合成値99,000。★1ならライトで約2年半 |

### 4.4 図鑑はすぐ埋まる

ライト（1日3,000回）でも、第1期52種は**1日目でほぼ全種（平均51.3種）**そろいます。
集める楽しみは「何が出るか」ではなく「どれだけ育ったか」にある、という設計です。

### 5.1 種類

| 種類 | 役割 | 数値 |
|---|---|---|
| **精霊** | 戦う本体。属性とスキルを持つ | 体・攻 |
| **霊獣** | 精霊に1体付けて守りを強化する | 体＋（少し）攻 |
| **霊具** | 精霊に1つ付けて攻撃を強化する | 攻 |

- **共鳴**: 霊獣・霊具が精霊と同じ属性なら、その数値が×1.5。
- ★3以上の精霊・霊獣・霊具はスキルを持つ（§5.4）。

### 5.2 属性と相性

```
      有利 →
  水 ───────▶ 火
  ▲            │
  │            ▼
  雷 ◀─────── 土

  光 ◀──────▶ 闇   （お互いに有利）
```

- 基本4属性は1周の関係: **水は火に、火は土に、土は雷に、雷は水に強い**。向かい合う組（水と土、火と雷）は相性なし。
- 光と闇は**お互いに有利**。基本4属性に対しては有利も不利もない（弱点がない代わりに、突ける相手もいない）。
- 有利な相手には与えるダメージ×1.1、不利な相手には×0.92。数字は小さいが、同じ★なら**有利側が約8割勝つ**（§6.4）。

### 5.5 期ごとの追加（2ヶ月で1期）

- 1期ごとに**13種**を追加する。目安: ★5 1・★4 2・★3 3・★2 3・★1 4。

## 6. 対戦

### 6.1 編成

- 精霊3体。それぞれに霊獣1体・霊具1つを付けられる（合計9枚）。
- コストや枚数制限はない。持っているカードの中から好きに組む。

### 6.2 1対1の戦い方

- 毎ラウンド、**両者が同時に攻撃する**（先攻・後攻はない）。どちらかの体力が0になったら決着。相打ちなら残り体力の割合で判定する。
- 1戦はだいたい2〜4ラウンド（平均2.9）。演出込みで10秒前後。

計算式:

```
体 = (精霊の体 + 霊獣の体 × 共鳴) × ランク補正
攻 = (精霊の攻 + 霊獣の攻 × 共鳴 + 霊具の攻 × 共鳴) × ランク補正

共鳴       = 精霊と同じ属性なら 1.5、違えば 1.0
ランク補正 = 1 + 0.03 × (ランク − 1)   ※ランク10が上限。カードごとに自分のランクで計算
ダメージ   = 攻 × 相性(1.1 / 1.0 / 0.92) × 乱数(0.7〜1.3) × 会心(20%で1.5倍) × スキル
```

- 乱数の幅を大きめ（±30%）にして、格上相手にも勝ち目を残している。
- 速さのステータスはない。数ラウンドで決着する戦いでは、先に殴れる側が勝ちすぎるため（試算では、速くて属性有利な側が97%勝った）。

### 6.3 三番勝負（読み合い）

1. 対戦相手が決まると、**お互いの精霊3体（と装備）が見える**。並び順は見えない。
2. 自分の3体を**先鋒・中堅・大将**に並べる（20秒）。
3. 同時に公開して、先鋒同士・中堅同士・大将同士で戦う。**2勝した方の勝ち**。

並び順は6通り。どこに有利な相性をぶつけるか、相手がそれをどう読むかの勝負になる。

### 6.4 バランスの目安（シミュレータの結果）

| 条件 | 勝率 |
|---|---|
| 同じ★、属性が有利 | 有利側 **約8割**（★1・★2は81〜84%、★4は73〜83%、★3はスキルの差で72〜88%） |
| ★が1つ上の相手（相性なし） | 下の側 14〜30%（★3からスキルが付くので★2→★3の差が大きい） |
| ★が1つ上の相手でも属性が有利 | 下の側 34〜63%（ほぼ互角） |
| 同じカードでランク4 vs ランク1 | 81% |
| ランク10の★1 vs ランク1の★3 / ★4 | 74% / 58% |
| ★5（ランク1） vs ★4（ランク1） | 62〜75% |
| 霊獣・霊具なし vs あり（同じ精霊） | 2% |
| 属性違いの装備 vs 同じ属性の装備（同じ★） | 27% |

三番勝負（A = ★3中心、B = ★4〜5中心、C = Bの相性を突く★4〜5）:

| 対戦 | 勝率（並び順はお互いランダム） |
|---|---|
| A ランク4 vs B ランク4 | 12% |
| **A ランク10 vs B ランク4** | **67%** |
| A ランク10 vs B ランク10 | 12% |
| C ランク10 vs B ランク10 | 37% |
| **C ランク10 が Bの並び順を読み切った場合** | **64%** |

ここから言えること:

- **合成が一番の強さ**。★3中心のデッキでもランク10まで育てれば、ランク4の★4〜5デッキに勝てる。
- 同じランクなら高レアが強い。★5を引く意味はある。
- 並び順を読み切ると勝率がほぼ倍になる。**属性の読み合いが勝敗を左右する**。

残っている調整点: ★3では炎舞姫（一閃）がやや強く、相性なしの鳴神に61%勝つ。山姫（鉄壁）はやや弱く、相性なしの霧姫に43%。スキルの数値で詰める。

### 6.5 対戦の形式

| 形式 | 内容 | 時期 |
|---|---|---|
| **ランク戦（非同期）** | 相手が事前に登録した防衛編成と戦う。相手の並び順は非公開 | 最初から |
| 決闘（リアルタイム） | 2人が同時に並び順を決める。フレンド戦・大会用 | 後から |

- 非同期戦では、同じ相手とは24時間再戦できない（並び順の総当たりを防ぐ）。
- 防衛側のレート変動は攻め側の半分。
- 対戦回数に制限はなし（くじ枠のような回復制にはしない）。

## 7. ランキングと報酬

### 7.1 レートと段位

- レート制（初期1000）。勝敗と相手との差で上下する。
- 期（2ヶ月）ごとにランキングを締める。次の期は、前の期の最終レートと初期値1000の中間から始める（例: 1800なら1400）。

| 段位 | レート |
|---|---|
| 見習い | 〜999 |
| 符術士 | 1000〜 |
| 霊術士 | 1200〜 |
| 召霊師 | 1400〜 |
| 霊将 | 1600〜 |
| 霊王 | 1800〜 |
| 天位 | 上位100名 |

### 7.2 報酬

報酬のガチャ券は**くじ枠を消費しない**（枠の外で引ける）。枠が一番の制約になるゲームなので、券の価値が高い。

| 段位 | 毎週 | 期末 |
|---|---|---|
| 見習い | 100回券 ×1 | 100回券 ×5 |
| 符術士 | 100回券 ×3 | 1000回券 ×1 |
| 霊術士 | 100回券 ×5 | 1000回券 ×2 |
| 召霊師 | 1000回券 ×1 | 1000回券 ×3 |
| 霊将 | 1000回券 ×2 | 1000回券 ×5 |
| 霊王 | 1000回券 ×3 | 1000回券 ×8 |
| 天位 | 1000回券 ×5 | 1000回券 ×10 |

### 7.3 名誉

- 期末の段位が**期の番号入りの称号**として残る（例: 「第1期 霊王」）。名前の横に1つ選んで表示する。
- 天位は専用の枠と、プロフィールの特別演出。1位は「第○期 天下一」。
- 段位以外の名誉: 累計引き数（10万回・100万回・1000万回）、初めてのランク10・ランク100など。

## 8. プロフィール

- **霊棚（たまだな）**: カードを最大5枚飾れる。並び順は自由。
  - 表示: カードの絵・★・ランク・ランク枠（§4.3）。
  - ★4以上は飾っているだけで動く（★4は光の粒、★5は全身が動く）。
- そのほかの表示: 名誉（称号）、現在の段位と今までの最高段位、累計引き数（「累計 1,234,567回」は自慢になる）、図鑑の達成率。
- ランキング・対戦結果・フレンド一覧から、他の人のプロフィールを見られる。

## 9. 演出

| 対象 | 演出 |
|---|---|
| ★1 | なし（まとめ表示の枚数だけ） |
| ★2 | カードの縁が淡く光る |
| ★3 | 符が属性の色に光る |
| ★4 | 封印の札が燃え尽きて、カットイン（2秒・スキップ可） |
| ★5 | 画面が暗転 → 千枚の符が舞う → 精霊が降りてくる（6秒）。ときどき★4の演出から★5に化ける昇格演出 |
| 1000連「千引き」 | 1000連だけの専用演出。符が渦を巻き、★5が含まれていれば渦が金色になる |
| ランクアップ | カードが重なって合わさり、数字が回って枠の色が変わる。ランク10・100は専用演出 |
| 対戦 | 有利な相性で当たったら「相性◎」の表示。★5のスキルが発動したら専用カットイン |

演出は**合計時間が伸びすぎない**ことを最優先にする。1日に数十回引くゲームなので、★3以下は一瞬で終わり、まとめ表示に集約する。

## 11. 運営・法令で気をつけること（要専門家確認）

- **コンプガチャの禁止（景品表示法）**: 有料くじで「違う種類のカードを決まった組み合わせでそろえると、別の景品がもらえる」仕組みは禁止。**図鑑コンプリート報酬は付けない**。同じカードを重ねるランクアップは「違う種類の組み合わせ」ではないと考えているが、要確認。
- **排出率の表示**: App Store・Google Playの規約で、有料のランダム要素は購入前に確率を表示する必要がある。レアリティ別とカード別の確率、天井の条件を表示する。
- **有償通貨（資金決済法）**: 有償通貨を残高として持たせると「前払式支払手段」になり、未使用残高が一定額を超えると届出などが必要になる（発行から6か月以内しか使えないものは対象外とされている）。上限突破は60分で使い切り、千引き札は即時消費にすれば、有償通貨の残高を持たずに済む。
- **未成年の課金**: 年齢別の月額上限を設けるのが一般的。上限突破は1時間400円まで払えるので、特に必要。

## 12. 技術メモ

- **抽選は必ずサーバー側**で行う。クライアントは結果を表示するだけ。
- 1日に数千〜数万回引くので、**1回ごとのレコードは保存しない**。
  - 保存するもの: カードごとの所持枚数・合成値・ランク、天井カウンタ、くじ枠の状態（無料枠の残り、最終回復時刻、上限突破の回数と期限、サブスク枠の残り）。
  - 抽選ログ: 1リクエストごとに「単位・シード・結果の集計」を残す（問い合わせ対応と監査用）。
  - 1000連は1000回ループせず、多項分布でまとめて抽選する。
- 対戦はサーバーでシードを決めて結果を計算し、クライアントにはシードと結果を返して演出だけ再生する。
- このリポジトリには Expo（React Native）のアプリが別にある。同じ構成（Expo＋TypeScript）でクライアントを作り、サーバーは Supabase や Firebase などのマネージドサービスを使うのが手軽。

## 14. 決めていただきたいこと

1. **最高レアの確率**: 1回0.07%に統一（推奨。10連0.7% / 100連6.8% / 1000連50%）か、ご要望どおり連ごとに1% / 8% / 50%か。
2. **1000枚ルール**: レアリティで合成値を変える（推奨）か、全カード一律1000枚か。
3. **無料枠の貯め**: 1000回まで貯められる（推奨）か、毎時リセットか。
4. **上限突破の「最大1000回」**: 追加分の合計が1000回（1時間で最大1200回、400円）か、1時間に引ける回数が1000回（300円で打ち止め）か。
5. **霊獣・霊具の使い方**: 精霊に付ける装備（この設計）か、精霊を強化するための素材（消費する）か。
6. **千引き札**: 即時消費型（推奨）か、貯めておける券か。
7. **サブスクの価格**。
